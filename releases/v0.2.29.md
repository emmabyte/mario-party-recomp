A fix for Bobsled Run in a wide window. Like v0.2.28 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `1159bd56730094bfc71be30113e1cfc8bacf34f3`). Other regions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioPartyRecompiled-v0.2.29-windows-x64.zip` and run `MarioPartyRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioPartyRecompiled-v0.2.29-linux-x64.tar.gz` and run `MarioPartyRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**Fixed:**

- In Bobsled Run in a wide window, the purple progress bar between the two views now runs from the window's left edge to its right, with the racers' icons, the start and the finish flag spread along it. Before, it stopped at the 4:3 picture's edges, with dark gaps beside it.

**Not checked yet:** long play sessions and rumble on a physical pad. Reports are welcome on the [issues page](https://github.com/n64hub/mario-party-recomp/issues).

The [README](https://github.com/n64hub/mario-party-recomp#readme) has what works and how to build it yourself. The same game also plays in a browser, with your ROM, at [n64hub.com](https://n64hub.com/#mario-party).
