The eleventh alpha of **online play** for two to four players, built on v0.2.14. It is a test build from the `netplay` branch of this fork, not a release of the main project. Like every release it contains no game data: each player needs their own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `1159bd56730094bfc71be30113e1cfc8bacf34f3`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioPartyRecompiled-v0.2.14-netplay-alpha.11-windows-x64.zip` and run `MarioPartyRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Mac (Apple Silicon, macOS 26 or newer):** unzip `MarioPartyRecompiled-v0.2.14-netplay-alpha.11-macos.zip` and open the app; if macOS blocks it, use System Settings > Privacy & Security > Open Anyway. Every player must use the same alpha.

**New since alpha 10:**

- **A player leaving no longer ends the game.** When a guest leaves, everyone waits and the host chooses: let the computer play for them, or take everyone back to the lobby (the host's lobby opens again on Resume Party and the others join it by themselves). The other players see why they're waiting.
- **Joining again.** A player who left can start the game again and use Join a Party with the host's address, whether everyone is still waiting or the computer has taken over. Everyone goes back to the start of the current scene together and the player takes their character back.
- **Back to the menu, not closed.** When the host leaves, or a session ends for another reason, the game goes back to Online Play and says why, rather than closing. The window blinks once as the game restarts.

**Earlier:** automatic resync (alpha 10); no desync when the players' windows have different shapes (alpha 9).

`ONLINE.txt` in the download says how to play. The host's UDP port 7845 must be reachable from the others: a shared VPN (Tailscale, Radmin VPN, ZeroTier) is easiest.

**Known:** a resync or a rejoin goes back to the start of the scene, so what was played since is played again.

Reports are welcome on the [issues page](https://github.com/emmabyte/mario-party-recomp/issues).
