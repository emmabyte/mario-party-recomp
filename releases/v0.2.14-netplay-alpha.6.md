The sixth alpha of **online play** for two to four players, built on v0.2.14. It is a test build from the `netplay` branch of this fork, not a release of the main project. Like every release it contains no game data: each player needs their own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `1159bd56730094bfc71be30113e1cfc8bacf34f3`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioPartyRecompiled-v0.2.14-netplay-alpha.6-windows-x64.zip` and run `MarioPartyRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64).

**New since alpha 5:**

- **Resume Party.** Every computer saves the party at the start of each scene. If a session ends early, the host chooses Resume Party in Online Play, the same players join again in any order, and the party picks up where its last scene started, each player as the player they were.
- **Less lag.** Each computer handles the others' packets the moment they arrive, rather than once a frame, which cuts about two frames from the input delay a connection needs.
- **A delay that follows the connection.** The game keeps measuring as you play: the delay goes up at once when the connection gets worse, and back down slowly once it's steady, so it doesn't keep changing under your hands.
- **A desync fixed.** A screen wipe could make the computers disagree about something that's only drawn, not played, and end the session. They no longer compare it.
- **Better desync reports.** If the game ever says it desynced, each player's record now names the memory that differs. Please send the newest `netplay/sessions` folder from every player.

`ONLINE.txt` in the download says how to play. The host's UDP port 7845 must be reachable from the others: a shared VPN (Radmin VPN, Tailscale, ZeroTier) is easiest.

**Known:** a player who drops out still ends the session for everyone (Resume Party brings the party back).

Reports are welcome on the [issues page](https://github.com/emmabyte/mario-party-recomp/issues).
