The seventh alpha of **online play** for two to four players, built on v0.2.14. It is a test build from the `netplay` branch of this fork, not a release of the main project. Like every release it contains no game data: each player needs their own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `1159bd56730094bfc71be30113e1cfc8bacf34f3`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioPartyRecompiled-v0.2.14-netplay-alpha.7-windows-x64.zip` and run `MarioPartyRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64).

**New since alpha 6:**

- **Smoother sound online.** The sound used to be made at a fixed pace per game frame, so whenever the game ran below full speed the sound ran short and kept breaking up. Each frame now makes as much sound as the time it really took, the same on every computer.
- **A guest leaving no longer freezes everyone.** If a guest closes the game, the others carry on at once with a computer player in their place. If their connection drops, the same happens after 5 seconds.
- **The host leaving ends the party cleanly.** Guests see a message straight away, and the host can bring the party back with Resume Party.
- **Speed and sound in the session log.** Every 20 seconds or so `session.log` notes how fast the game ran and how often the sound ran dry, to help track down any choppiness that's left.

`ONLINE.txt` in the download says how to play. The host's UDP port 7845 must be reachable from the others: a shared VPN (Radmin VPN, Tailscale, ZeroTier) is easiest.

**Known:** a guest who leaves can't rejoin the same session yet. Resume Party brings everyone back at the start of the last scene.

Reports are welcome on the [issues page](https://github.com/emmabyte/mario-party-recomp/issues).
