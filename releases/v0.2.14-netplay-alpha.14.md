The fourteenth alpha of **online play** for two to four players, built on v0.2.14. It is a test build from the `netplay` branch of this fork, not a release of the main project. Like every release it contains no game data: each player needs their own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `1159bd56730094bfc71be30113e1cfc8bacf34f3`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioPartyRecompiled-v0.2.14-netplay-alpha.14-windows-x64.zip` and run `MarioPartyRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Mac (Apple Silicon, macOS 26 or newer):** unzip `MarioPartyRecompiled-v0.2.14-netplay-alpha.14-macos.zip` and open the app; if macOS blocks it, use System Settings > Privacy & Security > Open Anyway. Every player must use the same alpha.

**New since alpha 13:**

- **A resync no longer leaves everyone on a black screen.** When a resync went back to the start of a scene after a minigame's results, the game waited for the results music to stop, but the board's music kept playing, so the game never went on. A resync now brings the sound back with the rest of the game.

**In alpha 13:** joining again works between Windows and Mac.

**In alpha 12:** the "left the party" question works; joining again is more reliable on a slow connection. **In alpha 11:** a player leaving no longer ends the game (the host chooses Computer plays or Back to lobby), a player who left can join again and take their character back, and a session that ends goes back to Online Play instead of closing.

**Earlier:** automatic resync (alpha 10); no desync when the players' windows have different shapes (alpha 9).

`ONLINE.txt` in the download says how to play. The host's UDP port 7845 must be reachable from the others: a shared VPN (Tailscale, Radmin VPN, ZeroTier) is easiest.

**Known:** a resync or a rejoin goes back to the start of the scene, so what was played since is played again.

Reports are welcome on the [issues page](https://github.com/emmabyte/mario-party-recomp/issues).
