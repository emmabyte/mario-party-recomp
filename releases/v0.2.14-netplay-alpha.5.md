The fifth alpha of **online play** for two to four players, built on v0.2.14, from the first real test between two PCs. It is a test build from the `netplay` branch of this fork, not a release of the main project. Like every release it contains no game data: each player needs their own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `1159bd56730094bfc71be30113e1cfc8bacf34f3`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioPartyRecompiled-v0.2.14-netplay-alpha.5-windows-x64.zip` and run `MarioPartyRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioPartyRecompiled-v0.2.14-netplay-alpha.5-linux-x64.tar.gz` (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType).

**New since alpha 3** (alpha 4 was a test build):

- **Online Play screens.** Online Play in the launcher now opens its own screens: type your name, then Host a Party or Join a Party (type the host's address, then Connect!).
- **A party lobby** in place of a black screen. It shows a place for each of four players, with their name, their connection to the host in milliseconds and whether they're ready, and the host's address to share. Everyone chooses Ready?, then the host's Let's Party! starts the game on every computer. Leave leaves the party on either side, and the others see it. If the host can't be reached, it says so.

**New in alpha 3:**

- **A Start Online Game button** at the bottom of Online Play.

**New in alpha 2:**

- **Online Play in the launcher.** Set it to Host (with how many play) or Join (with the host's address only: the host gives each player their number), then press Start Online Game. No scripts needed.
- **A delay that fits the connection.** The game measures the round trip when the session starts and sets the input delay from it, where the first alpha always used 3 frames, too short over a VPN.
- **Cleaner sound online.** The sound keeps a small cushion and corrects its speed gently, so a late frame no longer makes it crackle.
- **Desync reports.** Each player's copy keeps a record of the session in `netplay/sessions`. If the game says it desynced, please send the newest folder from every player: it lets the cause be found and fixed.

`ONLINE.txt` in the download says how to play. The host's UDP port 7845 must be reachable from the others: a shared VPN (Radmin VPN, Tailscale, ZeroTier) is easiest.

**Known:** the desync seen in the first test (around frame 2550) isn't fixed yet; its cause needs a record from this build. There is no rejoining a session that ended.

Reports are welcome on the [issues page](https://github.com/emmabyte/mario-party-recomp/issues).
