The ninth alpha of **online play** for two to four players, built on v0.2.14. It is a test build from the `netplay` branch of this fork, not a release of the main project. Like every release it contains no game data: each player needs their own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `1159bd56730094bfc71be30113e1cfc8bacf34f3`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `MarioPartyRecompiled-v0.2.14-netplay-alpha.9-windows-x64.zip` and run `MarioPartyRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Mac (Apple Silicon, macOS 26 or newer):** unzip `MarioPartyRecompiled-v0.2.14-netplay-alpha.9-macos.zip` and open the app; if macOS blocks it, use System Settings > Privacy & Security > Open Anyway. Every player must use the same alpha.

**New since alpha 8:**

- **No more desync on the first board when the players' windows have different shapes** (a Mac and a PC, a laptop and a widescreen monitor). In a window wider than 4:3 the board's camera was allowed further toward the map's edge, so it stood somewhere else on each computer. Online, the game now plays as if every window were 16:9; each window still shows the picture at its own shape.

`ONLINE.txt` in the download says how to play. The host's UDP port 7845 must be reachable from the others: a shared VPN (Tailscale, Radmin VPN, ZeroTier) is easiest.

**Known:** a guest who leaves can't rejoin the same session yet. Resume Party brings everyone back at the start of the last scene.

Reports are welcome on the [issues page](https://github.com/emmabyte/mario-party-recomp/issues).
